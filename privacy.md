# HSM Clinic Backup - Privacy Policy

HSM Clinic Backup is an administrator-operated backup utility for HSM Clinic.

## Data Access

The application uses Google Drive to store and manage encrypted database backups created by the clinic administrator.

## Data Protection

Backups may contain confidential patient records, medical visits, and prescriptions. They must be encrypted before being uploaded to Google Drive.

Patient records, backup files, passwords, and access tokens are never published in our public GitHub repository.

## Data Usage and Sharing

Google Drive access is used only for backup storage and management. Google user data is not sold or used for advertising.

## Data Retention

Backup copies are retained according to the clinic's configured retention policy. Removing an old backup does not delete the original patient records.

## Access Revocation

The administrator can revoke the application's access through Google Account security settings.
